## Architecture Summary

### Services (Both running in single container)
1. OpenViking Server (Port 1933)
   - Context database for AI agents
   - Web Studio UI
   - VikingBot framework
   - RESTful API

2. Ollama (Port 11434)
   - Local LLM service
   - Pre-cached models

### Pre-loaded Models
- Embedding: nomic-embed-text (306MB)
- LLM: mistral (4.1GB)
- Total: ~4.5GB in models alone
- Additional: ~2-3GB for runtime

### Process Management
- Supervisor manages both services
- Auto-restart on failure
- Centralized logging
- Health checks via curl

## Quick Deployment Steps

1. Prepare OpenViking repository:
   cd path/to/OpenViking

2. Copy files to repository root:
   (All files should be in same directory as Cargo.toml)

3. Build container:
   docker build -t openviking-complete .
   (Takes 15-30 minutes, includes model download)

4. Run with compose:
   docker compose up

5. Access:
   - Web UI: http://localhost:1933/studio
   - API: http://localhost:1933
   - Ollama: http://localhost:11434

## Customization Options

### Change Models
  ./manage-models.sh openviking-complete pull phi2
  ./manage-models.sh openviking-complete set-llm phi2

### Switch Provider
  Edit /app/.openviking/ov.conf (mounted volume)
  Restart container

### Enable GPU
  docker compose -f docker-compose.yml -f docker-compose.gpu.yml up

### Change Ports
  Edit docker-compose.yml ports section

### Adjust Resources
  Limit memory: docker run --memory=4g
  Limit CPU: docker run --cpus="2.0"

## Common Issues & Solutions

Issue: Build fails
→ Ensure you have 20GB free disk space
→ Try: docker system prune before rebuilding

Issue: Port already in use
→ Change ports in docker-compose.yml
→ Or: docker rm $(docker ps -aq) to clean

Issue: Models not loading
→ Check: docker logs openviking-complete
→ Models take 5-10 mins to cache on first run

Issue: High memory usage
→ Use lighter models: phi2 instead of mistral
→ Use: docker run --memory=4g to limit

Issue: Web UI not responding
→ Wait 60+ seconds for full startup
→ Check: curl http://localhost:1933/health
